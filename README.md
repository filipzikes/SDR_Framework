# SDR_Framework
Přiložený zdrojový kód byl vytvořen jako součást bakalářské práce na téma Zpracování dálkoměrných signálů pomocí SDR. Vyvinutý framework je určen k obsluze dálkoměrného systému pro určování polohy uvnitř budov, sestaveného z jednotek SDR ADALM PLUTO a využitím knihovny LibIIO (Analog Devices).
## English description
The attached source code was created for a bachelor's thesis on SDR-based Processing of Ranging Signals intended for indoor radiolocation. The framework served as controlling software for a demonstrated ranging system based on the SDR ADALM PLUTO, utilizing the LibIIO library from Analog Devices.
